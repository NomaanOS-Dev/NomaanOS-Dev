### ⚡ About Me
I am a systems architect and security researcher focused on **Sovereign AI Infrastructure, Edge AI Security, and Hardware Forensics**. My core philosophy revolves around decoupling probabilistic AI intent from deterministic operating system execution to achieve true digital sovereignty.

- 🔬 **Current Affiliation:** Project Scholar (GenAI & ML) @ IHFC – Technology Innovation Hub, IIT Delhi.
- 🛡️ **Core Focus:** Building fail-closed execution engines, immutable cryptographic evidence ledgers, and zero-trust local agentic stacks.

### 🚀 Flagship Architecture: NomaanOS
> *A 5-Layer Sovereign AI Stack designed for deterministic control and zero-trust edge computing.*

- **L1 Host Substrate:** Hardened Linux kernel environments with strict encryption baselines.
- **L2 NOS Exec:** Isolated, deterministic execution engine removing shell parsing vulnerabilities (`shell=False` strict allowlists).
- **L3 Sentinel Proxy:** Gatekeeper enforcing invariant security policies before intent reaches system layers.
- **L4 AEGIS:** On-device local LLM orchestration ensuring zero data leakage.
- **L5 Neural Lock:** Continuous behavioral validation frameworks.
